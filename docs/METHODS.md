# PeakForge 方法说明

[English](METHODS_en.md)

本页写明 PeakForge 实际计算了什么、依据哪些文献、有哪些已知局限。标 **[测试]** 的条目由
`tests/test_methods.py` 中的回归测试固定。代码在 `src/peakforge/core/`。

## 1. 约定
- 内部结合能（BE）升序，强度单位为每秒计数（cps）。
- 不对称拖尾朝**高结合能**（低动能）方向。
- 所有线型**面积归一**：分量的 `area` 就是积分强度。自旋轨道双峰的 `area` 指主峰（高 j），伴峰面积为
  `area·ratio`、位置 `center + split`。报告的面积、面积误差、占比和 at% 一律用**双峰总面积**。

## 2. 线型（`lineshapes.py`）
| 名称 | 定义 | `fwhm` 的含义 |
|---|---|---|
| `gaussian`、`lorentzian` | 标准形式 | 真实半高宽 |
| `pvoigt` | η·L + (1−η)·G，二者面积归一、半高宽相同 | 真实半高宽 |
| `voigt` | scipy `voigt_profile`；高斯宽度由 Olivero–Longbothum 关系 f_V ≈ 0.5346 f_L + √(0.2166 f_L² + f_G²) 反解，f_L = η·f_V | 真实半高宽（该关系精度约 0.02 %） |
| `gl` | CasaXPS GL(p) **乘积**形式 exp[−4 ln2 (1−m) u²/w²] / (1 + 4m u²/w²)，m = p/100 | 0 < m < 1 时**不是**半高宽（GL(30) 窄 4 %）；结果另给“实测 FWHM” **[测试]** |
| `sgl` | CasaXPS SGL(p) **加和**形式 (1−m)·G + m·L（G、L 峰高归一） | 真实半高宽 |
| `ds` | Doniach–Šunjić：cos[πα/2 + (1−α) arctan(ε/γ)] / (γ² + ε²)^((1−α)/2)，ε = −(BE − center)，再与高斯卷积 | 高斯半高宽；洛伦兹宽度为 `gamma` |
| `la` | 不对称洛伦兹：高 BE 侧 L^α、低 BE 侧 L^β，再与半高宽 `gw`（eV）的高斯卷积 | 洛伦兹半高宽 |

局限：
- **DS 面积依赖积分范围。** α > 0 时 DS 积分发散，因此在 [center − (8w+1), center + (25w+4)] eV（w 为最大宽度）内
  归一（两侧最外 10 % 用余弦渐降），范围外为零。DS 分量的“面积”和占比指该范围内的面积。其他软件也有类似约定，但**数值不完全相同**，
  DS 面积只宜在 PeakForge 内部比较。
- **LA 参数与 CasaXPS 的 LA(α, β, m) 不通用。** CasaXPS 的高斯宽度 `m` 以数据点（通道）计，PeakForge 的 `gw` 以 eV 计；
  峰形可以对上，参数值不能直接照抄。
- `gl` 与 `sgl` 解析计算并在整个实轴上归一：GL 面积 = w·(π/√b)·erfcx(√(a/b))，a = 4 ln2 (1−m)，b = 4m；
  SGL 面积 = w·[(1−m)√(π/4 ln2) + m·π/2] **[测试]**。
- 不对称线型（ds、la）在覆盖上述范围的 2049 点网格上计算（步长约 w/40）后插值；点数固定加上两端渐降，使峰形对所有参数都是光滑函数——
  有限差分雅可比矩阵（因而所有误差）依赖这一点 **[测试]**。
- **阶段 1 已修正：** GL、SGL、DS、LA 原先用的网格点数随宽度跳变（步长 min(0.02, w/15)），DS/LA 在范围边缘突然截断。
  于是 20–45 % 的宽度下 ∂峰形/∂fwhm 是错的，最多差 10⁴ 倍——例如 SGL 拟合报出 FWHM ± 7·10⁻⁸ eV。拟合值几乎不受影响，
  受影响的是误差与收敛。SGL 面积原先在截断网格上归一（w = 1 eV 时洛伦兹部分少约 2 %），现在与 `lorentzian`、`pvoigt` 一样在整个实轴上归一。

## 3. 背景（`background.py`）
端点强度在背景范围内取 `avg` eV（默认 0.5）的平均；范围外背景保持端点值。
- **linear**：两端点平均值之间的直线。
- **shirley**：迭代 Shirley（Shirley 1972；Proctor & Sherwood 1982）：B(E) = y_lo + (y_hi − y_lo)·∫_lo^E [y − B] / ∫_lo^hi [y − B]，迭代至收敛。
- **smart**：每次迭代都限制 B ≤ 数据（同 CasaXPS “Smart”）。
- **tougaard**：B(E) = ∫_{E'<E} K(E − E') [y(E') − y_lo] dE'，
  K(T) = B·T / [(C − T²)² + D·T²]（三参数 U3；Tougaard 1997；Tougaard 2024 式 2）。
  默认用**通用二参数 U2(1643)**：K = B·T / (C + T²)²，C = 1643 eV²（Tougaard 1989；Tougaard 2024 式 1），
  适用于过渡金属及其合金、氧化物。U2 写成 D = 4C 的 U3（代数上完全相同）**[测试]**。
  有尖锐等离激元的材料可选文献预设：U3 Al (C, D) = (230, 4.5)、Si (325, 96)、聚合物 (551, 436) eV² **[测试]**。
  - B **不按输入值使用**：背景整体缩放到与高 BE 端点平均值相接（拟合软件的常见做法；QUASES 类分析则由归一化确定 B）。
  - 不含带隙起始 Θ(T − E_g)；假定能量步长均匀。
  - **0.1.x 已修正：** 0.1 在 U3 公式里用 (B, C, D) = (2866, 1643, 1)，既不是 U2 也不是任何已发表的 U3，
    在 T ≈ 40 eV 附近接近奇点。用该值保存的模型在载入时自动改为 U2 **[测试]**。
- 背景在拟合峰**之前**算好并固定。两个端点平均值的噪声会传播进报告的误差（第 5 节）；背景类型与端点位置的选择不计入。
- **局限（阶段 1，SASJ 测试谱）：** Shirley/Tougaard 背景假定台阶来自所拟合的峰本身。若窗口内有**其他**信号带来的下降或有结构的
  背景（Au 4f 下的 Cu 3p 尾巴、弱 Ag 3d 下的 Au 4d 损失结构），所有可选背景都会使面积偏差 5–40 %。应选择窗口与端点使外来结构很小，
  或用额外组分把它拟合出来。

## 4. 噪声模型、加权与 χ²ᵣ（`fit.py`）
**采集时间。** 计数 N = cps · t，t 为每个数据点的有效采集时间：
| 格式 | t | 依据 |
|---|---|---|
| VAMAS（ISO 14976） | dwell × 扫描次数；纵坐标除以 t，除非其单位已是 c/s | 标准 |
| PHI .spe | dwell（**不乘** sweeps） | PHI Genesis 实测数据：存储 cps 的逐点方差与 cps·dwell 的泊松统计一致——用下文四阶差分估计量（阶段 1 复核），两个样品 10 个窄谱区（C 1s、O 1s、K 2p、Ir 4f 为 3 次扫描，Ta 4f 为 5 次）方差比 0.65–1.52（平均约 1.0），3 个全谱 0.82–1.04；若按 cps·dwell·sweeps 则为 2–5 |
| CSV / Excel 自动识别 | 未知 → 由数据估计 | — |
| CSV / Excel 列映射模板，`intensity: cps` | 给了 `acq_time` 就用，否则由数据估计 | 用户声明 |
| CSV / Excel 列映射模板，`intensity: counts` | 给了 `acq_time` t 则 cps = counts / t；否则 t = 1 s（cps = counts，计数 N 精确） | 用户声明 **[测试]** |

**噪声 σᵢ。** 已知 t：σᵢ = √(yᵢ·t)/t（泊松，用数据方差）。未知：σᵢ² = k·yᵢ。拟合前 k 由数据二阶差分粗估（权重只用 σ 的形状）；
**拟合后**由残差的四阶差分 dᵢ = rᵢ₋₂ − 4rᵢ₋₁ + 6rᵢ − 4rᵢ₊₁ + rᵢ₊₂（白噪声方差 = 70 σ²）重新估计：
k = median(dᵢ²/70·包络ᵢ)/0.455 · n/(n − 自由参数数)（方差 ∝ 强度；已扣背景、围绕零的数据沿用拟合前选定的常数方差模型 **[测试]**）。表格数据的 χ²ᵣ 与已知 t 时的“数据噪声 / 计数噪声”之比都用这个 k **[测试]**。
拟合模型去掉了峰，四阶差分去掉了平滑的失配，因此峰占满窗口或步长较粗时仍无偏（步长 0.05–0.5 eV、FWHM 0.6–1.2 eV：±15 % 以内）；
150–300 点的谱单次散布约 ±15–20 %。比值超出 0.5–2 时诊断提示采集参数与实际噪声不符；步长粗且 χ²ᵣ ≫ 1 时，超出部分也可能是逐点的线型失配（提示中会说明）。
- **阶段 1 已修正：** 原先拟合前的二阶差分中位数在峰占窗口较大比例时被峰曲率抬高（Au 4f 类窗口：0.1 eV 步长 ×2–3，0.5 eV 步长 ×50；
  原因是噪声点与曲率点混合后的中位数），表格数据的 χ²ᵣ 因此偏低同样倍数。

**加权。** `none`：普通最小二乘。`poisson`：残差乘 1/σᵢ（只用相对权重，解与 t 无关）。

**χ²ᵣ** = Σ(残差ᵢ/σᵢ)² / (n − 自由参数数)，**与加权方式无关** **[测试]**。≈1 表示失配与噪声同级；噪声为估计值时显示为“≈”。
背景是固定的，其端点平均值的噪声也会进入 χ²ᵣ：每端只有 2–3 个点平均（粗步长）时，即使峰模型正确，χ²ᵣ ≈ 1.5 也属正常。
高计数谱常见 RMS < 1 % 而 χ²ᵣ ≫ 1：说明模型在统计上不完整（线型、背景），但不一定影响所关心的结论。
- **0.1.x 已修正：** 0.1 在泊松加权时先把权重归一再算 χ²；不加权时用 std(Δy)/√2 作噪声，混入了峰的斜率（χ²ᵣ 远小于 1）。拟合值本身不受影响。

## 5. 不确定度
- 自由参数协方差：把数据噪声线性传播到参数，Δp = A·Jᵀ·W·(I − G)·Δy，即**三明治估计** A·M Σ Mᵀ·A，M = Jᵀ·W·(I − G)，
  A = (JᵀJ)⁻¹，Σ = diag(σᵢ² · χ²ᵣ)，W = diag(wᵢ)，J 为解处加权残差的雅可比矩阵。G = ∂背景/∂y：背景由同一份含噪数据算出，
  主要通过两个端点平均值，故 G = Σ_端点 g·uᵀ（u 为平均权重，g 为背景对该平均值的响应，有限差分求得）；与完整的 ∂背景/∂y 相差
  < 3 %（Shirley、Smart、Tougaard、线性）。乘 χ²ᵣ 吸收模型失配与估计噪声的标度。没有噪声模型时用 A·s²，s² = RSS/自由度。
  泊松数据上，加权与不加权拟合报告的 1σ 与多次噪声实现的实际散布相差约 10 % 以内 **[测试]**
  （0.1 用 A·s²，不加权拟合时误差低估约 1.7 倍）。
- 派生量（表达式绑定的参数、双峰总面积、百分比占比）用数值梯度做线性传播 **[测试]**。
- **阶段 1 已修正：** 不含 G 时，Shirley 背景下面积 1σ 小了 1.6–2.8 倍（40–150 次噪声实现，端点平均 0.5–2 eV）**[测试]**。
  Smart Shirley 仍低估约 1.2 倍：迭代中的截断使背景还依赖内部各点，G 未覆盖。
- 有系统失配（χ²ᵣ ≫ 1）时，乘 χ²ᵣ 使 1σ 大于仅由噪声造成的散布（SASJ 金属谱、0.5 eV 步长：峰位 5–15 倍、面积约 2 倍）。
  这是有意的：此时报告的误差包含了模型失配。
- 未包含：背景类型与端点的选择、线型选择。处于边界的参数误差没有意义（列在“触边界”中）。

## 6. 模型比较与稳定性（`diagnostics.py`）
- AIC = n ln(RSS/n) + 2k，BIC = n ln(RSS/n) + k ln n（加权 RSS；高斯似然近似）。
- **去掉某分量的 ΔBIC**：逐个去掉分量、其余重新拟合。ΔBIC > 10 强、2–10 有支持、< 2 数据不支持
  （对 Kass & Raftery 1995 的合并：2–6 positive、6–10 strong、> 10 very strong）。若去掉后反而拟合更好，说明完整模型落在局部极小。
  ΔBIC 假定残差处于噪声水平；有系统失配（χ²ᵣ ≫ 1）时会高估多加分量的证据。
- **多起点稳定性**：最多 12 个随机起点，代价在最优 2 % 以内的解相互比较，占比散布 > 3 % 时提示。
- |r| > 0.95 的参数相关会列出。

## 7. 荷电校正（`quant.find_c1s_reference`）
先扣 Shirley 背景，再在 283–287 eV（未校正 BE）内最强峰的低 BE 侧和峰顶拟合单个 GL(30)，位移使其对到参考值
（默认 284.8 eV，项目设置）。以下情况**拒绝给出结果**（位移不变、列出该样品）：最大值距窗口边缘不足 0.3 eV、
没有明显的峰、拟合偏移 > 0.95 eV **[测试]**。污染碳定标本身有零点几 eV 的不确定度，对某些样品会失效
（Greczynski & Hultman 2020）；有内标时优先用内标。

## 8. 定量（`quant.py`）
at%ᵢ = (Aᵢ/RSFᵢ) / Σⱼ(Aⱼ/RSFⱼ)，A 为拟合总面积（或扣背景后的积分）。内置 RSF 是近似的 Scofield（1976）Al Kα 截面，
以 C 1s = 1 归一，**未做**分析器透射函数、非弹性平均自由程、角度不对称校正：绝对 at% 可能偏差数十个百分点。
定量工作请填写本仪器的 RSF（已含这些因素）。该说明会显示在界面和 Excel 导出中。

## 9. 参数表达式
`Ir0.center + 1.1`、`O_lat.fwhm`、`max(A.center, 3) - sqrt(4)` 这类表达式先解析成语法树再求值，不使用 Python `eval`：
只允许数字、`+ − × / **`、正负号、`abs min max sqrt exp log`、`pi` 和 `分量.参数` 引用，其他一律拒绝 **[测试]**。
模型在载入或设置时校验（`schema.py`，也可 `peakforge validate`）：引用不存在的分量/参数、循环表达式、min > max、
线型和任何表达式都不用的自由参数（拟合无法确定，通常是拼写错误）、未知线型或背景、拟合范围与数据不重叠为**错误**，模型被拒绝；
初值超出上下限、自旋轨道面积比固定值偏离轨道表 (2j+1) 值 > 5 %、劈裂偏离表值 > max(0.3 eV, 10 %)、每 3 个点多于 1 个自由参数为**警告** **[测试]**。
允许辅助参数（如 `Ir0.center + Ir3.shift` 中的 `Ir3.shift`）。
